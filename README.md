# CAVVE PLAY

个人游戏试玩站：https://cavve77.github.io/

当前试玩：Rhythm Realm 0.0.2
https://cavve77.github.io/games/rhythm-realm/0.0.2/

本仓库只保存网站和浏览器运行产物，不包含游戏 TypeScript 源工程、源码映射、完整工程压缩包、Android 工程、安装包、测试音乐或开发记录。

网页运行文件必须发送到浏览器，可被下载与分析。关闭源码映射和压缩代码不能保证运行逻辑保密。访客页面只提供网页试玩入口，不提供源码和安装包下载按钮。

导入的音乐由玩家浏览器本地处理，不上传到站点。

GitHub Pages 使用 main 分支根目录，.nojekyll 保留静态资源路径。

公开访问不代表授予游戏、素材或代码的开源使用许可。
